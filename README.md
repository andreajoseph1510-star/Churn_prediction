Overview:

SenseChurn is an end-to-end machine learning application designed to predict customer churn in the telecom industry.
It provides risk classification (High / Medium / Low) along with interactive insights to help businesses improve customer retention strategies.
The project goes beyond model building by delivering a complete, user-friendly web application with dashboards, AI assistance, and secure authentication.

Problem Statement:

Telecom companies often lose customers without early warning signs.
This project aims to:
Predict customers likely to churn
Understand key factors influencing churn
Provide actionable retention insights

Tech Stack:

Python
Streamlit (Web Application Framework)
Plotly (Interactive Data Visualization)
XGBoost (Machine Learning Model)
SMOTE (imblearn) (Handling class imbalance)
Pandas (Data manipulation)
NumPy (Numerical computing)

Key Features:

Customer churn prediction (High / Medium / Low risk)
Interactive dashboards using Plotly
Customer behavior trend analysis
AI-powered retention strategy assistant
Downloadable customer reports
Secure login system using Firebase authentication

How to run:
##  How to Run the Project Locally

###  Clone the repository
git clone https://github.com/andreajoseph1510-star/Churn_prediction.git
cd Churn prediction app

###  Install dependencies
pip install -r requirements.txt

### Run the Streamlit app
streamlit run app.py
